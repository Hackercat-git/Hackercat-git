## 🛠️ What I build

### 🔑 [PassPy](https://github.com/ByteBellSoftware) — Password Manager Suite
A full cross-platform password manager built from scratch.
Available on: CLI · Desktop · Android · iOS · Firefox · Chrome · PWA · Local Server · YubiKey

### 📊 [PurrFileGenerator](https://github.com/Hackercat-git/PurrFileGenerator) — GitHub Stats Card
Generates an animated SVG stats card for any GitHub profile.
Zero dependencies · 15 themes · 15 palettes · dark/light mode

### 🕵️ [Pawprint](https://github.com/Hackercat-git/Pawprint) — Network Scanner Reports
Turns nmap output into clean, readable HTML reports.

### 🖥️ [Purrmox](https://github.com/Hackercat-git/Purrmox) — Proxmox Dashboard
Personal status dashboard for Proxmox homelab clusters.
